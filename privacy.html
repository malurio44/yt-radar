Privacy Policy

YT Radar · Last updated: 25 October 2026

YT Radar is a personal, non-commercial research tool run by an independent developer. It helps a YouTube creator find small channels whose recent videos are performing far above their usual level, as reference material for content ideas. This policy explains what data the tool uses and how it is handled.

YouTube API Services

YT Radar uses YouTube API Services to read public channel and video information. By using YT Radar you agree to be bound by the YouTube Terms of Service. YouTube's use of data is governed by the Google Privacy Policy.

Information we collect from visitors

  • YT Radar has no user accounts, no sign-in and no forms. It does not ask for or collect names, email addresses or any other personal information from visitors.
  • YT Radar does not use cookies, analytics, advertising or tracking scripts, and does not access or store any information on your device.
  • YT Radar does not use OAuth and never accesses any YouTube account or private YouTube data.
  • The site is hosted on GitHub Pages. GitHub may log technical information such as IP addresses when pages are served; see the GitHub Privacy Statement. YT Radar does not receive or use these logs.

YouTube data we use

  • Only public data returned by the YouTube Data API and YouTube's public RSS feeds: channel titles, handles, descriptions, thumbnails, subscriber/view/video counts, and public video titles, thumbnails, durations, publish dates and view counts.
  • This data is used only to show, for each channel, how its recent videos and subscriber count compare with its own earlier numbers.
  • The data is never sold, shared with third parties, used for advertising, or combined with data from other sources.

Storage, refresh and deletion

  • YouTube data is stored in a local database on the developer's own computer, and a daily summary is published on this site.
  • Public statistics (subscriber, view and video counts) are kept for up to 36 months to show changes over time. Other YouTube API data is refreshed or deleted within 30 days.
  • Channels or videos that become private, deleted or unavailable stop being tracked and are removed from the published page.

Removal requests and contact

Channel owners who want their channel removed from YT Radar, or anyone with a privacy question, can open an issue at https://github.com/malurio44/yt-radar/issues. Removal requests are handled within 7 days.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
